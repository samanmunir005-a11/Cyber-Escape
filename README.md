# 🔐 Cyber Escape

Cyber Escape is an interactive cybersecurity-themed game built using **HTML, CSS, and JavaScript**. Players solve different challenges to escape a hacked computer system.

### 🎮 Features

* Multiple cybersecurity-themed challenges
* Different game levels
* Score and lives system
* Instant feedback for answers
* Game Over and Win screens
* Interactive and user-friendly interface

### 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

### 🎯 Purpose

This project was created to practice **HTML, CSS, and JavaScript** while developing an interactive and engaging web-based game.
